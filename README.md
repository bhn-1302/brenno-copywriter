Portfólio focado em copywriting e criação de páginas que geram ação.

- Landing page sobre burnout
- Página para pet shop
- Página de vendas de pururuca

Demonstrar habilidade em escrita persuasiva, estratégia de comunicação e construção de páginas focadas em conversão.
